# UI screens

1. Login
   - Email/password
   - Demo credentials
   - Error state

2. Employee Dashboard
   - Welcome/profile card
   - Attendance summary
   - Quick refresh/action

3. Admin Dashboard
   - Employee count
   - Payroll total
   - Attendance distribution
   - Leave distribution

4. Attendance
   - Check-in/check-out actions for employee
   - Daily/weekly-style records table
   - Status pill

5. Leave
   - Employee application form
   - Admin approval/rejection queue
   - Status and remarks

6. Payroll
   - Basic salary
   - Allowances
   - Deductions
   - Net salary

7. Employees
   - Admin employee directory
